# Images  Upload Guide for Yonatan Nigussie Portfolio

Place your photos in this folder using the exact filenames below.
All images should be JPG format. Recommended minimum width: 1800px for grids, 2400px for hero/full-bleed slots.

## Tips
- Portrait-ratio images (3:4) work best for Faces Untold and Journal sidebars
- Landscape (16:9 or wider) works best for hero, morning, and rural shots
- Keep files under 2MB each for fast loading (compress with tools like Squoosh or TinyJPG)
- Black & white or lightly desaturated images match the site's aesthetic
